# Task 2: Creating a Microsoft Azure Account ☁️

**Domain:** Cloud & DevOps Summer Training  
**Objective:** To successfully set up and activate a Microsoft Azure Free Tier account to provision and manage cloud resources for upcoming DevOps tasks.

---

## 📝 Overview
In this task, we navigated the Microsoft Azure portal to register for a Free Tier account. This account provides access to popular Azure services free for 12 months, along with an initial credit to explore premium cloud resources.

## 🛠️ Prerequisites
* A Microsoft Account (Outlook/Hotmail/GitHub)
* A valid mobile number for OTP verification
* A valid Visa Credit/Debit card for identity verification

---

## 🚀 Step-by-Step Implementation

### Step 1: Navigating to the Azure Portal
Went to the official [Microsoft Azure Free Account](https://azure.microsoft.com/en-us/free/) page and clicked on **"Start free"**.


### Step 2: Signing In
Logged in using my existing Microsoft credentials to initiate the registration process.


### Step 3: Identity Verification
Filled in my basic profile details (Name, Email, Phone Number) and completed the identity verification process via OTP.


### Step 4: Adding Payment Information
Entered my Visa card details. Azure requires this strictly for identity verification to prevent spam and bot accounts. **No charges are made without explicit consent** to upgrade to a Pay-As-You-Go subscription.


### Step 5: Accessing the Azure Dashboard
After successful verification, the account was created. Navigated to the Azure Portal dashboard, where all cloud resources (VMs, App Services, databases) can be managed.

## 🎯 Key Takeaways
* **Identity Verification:** Cloud providers like Azure use card details primarily to establish a unique identity and prevent fraud.
* **Free Tier Limits:** It's crucial to understand the limitations of the free tier (e.g., specific compute hours, bandwidth limits) to avoid accidental billing during the training.
* **Dashboard Navigation:** Got familiar with the Azure Portal interface, which will be the central hub for our upcoming DevOps deployments.
